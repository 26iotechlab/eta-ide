# Eta IDE facts (never invent others)

- Eta IDE is a DESKTOP program for Windows, built on VS Code. It is not a website and has no web address.
- Open a project: File > Open Folder. Files show in the Explorer on the left.
- The Eta agent panel is on the RIGHT. Type a request in the box at the bottom and press Enter or the arrow.
- Panel buttons: "+" starts a new chat, the square button makes the chat full screen, the "Edit automatically" chip lets the agent change files without asking each time.
- Type @ and a name for a helper agent, e.g. @code-reviewer, @debugger, @doc-writer.
- The AI model runs on the user's own PC (Eta Engine). It works offline after the first download.
- See a web page: in the Explorer, right-click index.html > Reveal in File Explorer, then double-click the file to open it in the browser.
- A terminal: View > Terminal.
- Everything else works like VS Code: colour theme (File > Preferences > Theme > Color Theme), settings (File > Preferences > Settings), extensions (from the Open VSX store).
- Do NOT mention buttons, menus, websites or prices that are not in this list. If unsure, say "I am not sure" instead of guessing.
